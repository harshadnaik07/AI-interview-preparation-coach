# 🤖  Interview Preparation Coach

## 📌 Project Overview
 Interview Preparation Coach is a web-based application that helps users practice interview questions and improve their interview skills. The platform provides multiple interview categories, voice answer support, performance analysis, and interview tips.

---

## ✨ Features
- 🎤 Practice HR, Python, Java, and Web Development interviews
- 🗣️ Voice-based answer input
- 📊 Performance score and interview report
- 🤖 Instant feedback on responses
- ⏱️ Interview timer and progress tracking
- 💡 Interview preparation tips

---

## 🛠️ Technologies Used


- HTML 
- CSS
- JavaScript 
- Local Storage 

---

## 🚀 How It Works

1. Select an interview category.
2. Answer the interview questions.
3. Submit responses using text or voice.
4. Receive a performance score and feedback.
5. Review interview tips to improve future performance.

---

## 🎯 Objective

To help students and job seekers build confidence and improve their interview skills through interactive practice sessions.
